# FJ-automotive

A responsive HTML website demo for FJ Automotive Diagnostics & Repairs in Polokwane.

## Preview

Open `index.html` in a browser. No installation or build step is needed. Keep
`styles.css`, `script.js`, and the `assets/` folder alongside the HTML file.

Fonts, Google Maps and WhatsApp links require an internet connection. Images and
the hero video are stored locally.

## Features

- Navy Trust visual theme with Space Grotesk and DM Sans typography
- Muted automotive video hero with pause controls and an image fallback
- Animated hero entrance and scroll-driven word reveals
- Mobile navigation and reduced-motion support
- Service details and an illustrative price guide
- Booking form that prepares a WhatsApp request for the visitor to send
- Floating WhatsApp contact button, map and directions
- Local service assistant with prepared answers

## Demo content

Prices are illustrative and require confirmation by the business. Bookings are
requests, confirmed only when the workshop responds. The assistant uses local
rules and is not connected to a live AI service. Business details and service
availability should be reviewed before using this as a production business site.

The photography and footage are illustrative stock assets, not images of FJ
Automotive's premises or staff. See [video credits](assets/VIDEO-CREDIT.md).

## Files

- `index.html`: content and page structure
- `styles.css`: layout, responsive styling and hero animations
- `script.js`: booking preparation, navigation, assistant and scroll/video behaviour
- `assets/`: local photographs, video, poster, favicon and video credits

The site can be served by any static web host. No credentials or backend services
are included.
